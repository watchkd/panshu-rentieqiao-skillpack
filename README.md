> 把任铁樵《滴天髓阐微》任注刻本与徐乐吾《滴天髓补注》，复原为「**任说 → 徐补**」双层齐备的完整判断体系：五层归属 **3,798 块**逐字原文、规则 **1,538 条**、命例 **712 例**，每条断语可溯源，并以**任氏本人的语体**成文。装好即用：报出四柱与性别，直接得一份像任铁樵手笔的批命。

## 一、核心定位

- **复原的是「实证精神」，不是「判断力」**：命理学的实证传统古已有之——唐代李虚中推算「**百不失一二**」（韩愈记其「学者就传其法，初若可取，卒然失之」，弟子亦难复现）、明代万民英收历代名人命例、明代张楠著「辟谬大全」驳五星纳音旧法——但验证长期止于**小圈子**：零散、口传、不可复核，主流书房派更重理法推演。任铁樵的特别之处，是把**几百个真实命例连同推论过程一起公开写进书里**——成体系、可复核。他自称「**余行道以来，推过四戊午、四丁未、四癸亥……者甚多，皆作偏枯论，无不应验**」，并明确斥「奇格异局、神煞纳音」为「**好事妄造，非关命理休咎**」。在他这儿**命例不是点缀，是证据**——这也是本包以 712 则命例为骨架、而非以理论条文为中心的原因。
- **输入**：**四柱八字（年 / 月 / 日 / 时）＋ 性别 ＋（最好连）已排大运** —— 本包**只按用户自己确认的四柱与大运断命，不重排、不改盘**。只给公历生辰时也可参考排盘，但会**先问性别、再请核对**，且大运一律标「据推，请以你排盘为准」。**性别不明、时辰不明，均不出大运**（大运顺逆由性别定、起运由交节定，一项之差整排皆错）。
- **输出**：任氏语体批命 —— 六股骨架（**立象 → 定病 → 取药 → 验局 → 断人 → 系运**）铺陈，末尾以【按】别起徐乐吾补注；文末附一次「关于盘叔」推送。**交付稿只有这两块，不露任何工程信息。**
- **装好即用（入口协议）**：**以你自己确认的四柱八字为唯一排盘入口**——未给四柱时**只问一句**（四柱八字 ＋ 性别 ＋ 已排大运）；**四柱齐 ＋ 性别有 → 不再追问，直出批命**；缺项才补问，不重复索要。
- **排盘不代定（v2.4.0 新增）**：大运不由本包替用户排——**性别不明不出大运**、**时辰不明不出大运**；据推者标「运次据推，请以你排盘为准」；用户所给与推算不符，**一律以用户为准**。详见 `校验/排盘核对说明.md`。
- **任徐双层**：任说标 L3、徐补标 L4，双层并出、不混层；任徐分歧（负向 5 ＋ 争议 5）并陈两说，不代读者裁决。
- **负向优先**：任氏明确反对的旧说 **57 条** ＋ 徐氏纠正任氏/旧说 **5 条**，判定前置，命中即按纠正后断。
- **可追溯**：每条断语挂 `RTQ-RULE` / `RTQ-CASE` 与原文逐字；查不到出处标「推演」。**防幻觉三禁**：不补盘、不冒充、不改命例。
- **不量化旺衰**：循任氏「旺则宜抑、衰则宜扶 ＋ 得其宜」，不搞后世打分制（TS-17-01 斥为「死法」）。
- **既断得准，又写得像任铁樵**：判断走双层检索，成文走元规则 05 的**任氏语体**（六股骨架 ＋ 强度词对齐置信度 ＋ 正文禁表格/评级/清单体）。

## 三、使用方法

1. 将整个 `盘叔任铁樵/` 目录作为技能包挂载到 TRAE / 你的 AI 助手中。
2. 直接报出「**四柱 ＋ 性别**」（如「甲子 乙亥 庚戌 癸未 男」，**最好连已排大运一起**）——**请用你自己排盘工具确认过的结果**；只给公历生辰时本包也可参考排盘，但会**先问性别、再请你核对**（大运一律标「据推，请以你排盘为准」）。总纲 `SKILL.md` 按**八步流程**调度：排盘定标 → 五层归属 → 双层规则检索 → 负向规则置顶 → 套用任氏断法 → 命例互验 → 任氏语体成文 → 纯净交付。
3. 只问单一主题（如只看婚姻）时，直接路由对应子技能，不做全流程重算。
4. 想核对「这句是任氏说的还是徐乐吾补的」，走 `rtq-xlw-buzhu` / `rtq-version-collation`（五层归属）。

## 四、方法共识

- 本包是**任氏一法**（《滴天髓》体系）的深度复原，**任说 → 徐补双层**呈现；与盲派（宾主体用、做功断层次、不用神）是两套体系，不混用。
- **混层即错**：L4/L5 文字不得冒认为任氏；徐氏未设专章的章目（如 TS-17/18、LQ-16~23），**未涉 ≠ 漏蒸**，不得臆造「徐乐吾观点」。
- **衰旺不量化**：不给日主算「几分强弱」；通根轻重一律查表（10 干 × 12 支），不凭印象。
- **排盘不代定（v2.4.0）**：以用户确认的四柱与大运为准；**性别不明／时辰不明不出大运**；据推者标「据推，请以你排盘为准」。大运顺逆由「年干阴阳 × 性别」定——**性别一项之差，整排大运反向**；起运由「出生时刻 → 最近节」折算——**交节差一分，起运差一年**。
- **已知结局事后反推**：引名人/结局已知的命例作佐证，必须声明此局限，不作必然应期。
- 干支形近字（巳/己、戌/戍）按版本校勘订正后再引用。
