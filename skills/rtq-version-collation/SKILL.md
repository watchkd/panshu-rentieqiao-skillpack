# rtq-version-collation · 版本校勘技能（第④组「版本保险组」）

## 一、这个技能解决什么

防止出现这句要命的话：**「任铁樵认为……」——其实是徐乐吾说的。**

本技能**不论命**，只做四件事：
1. **作者归属判定**：一段文字属于 L1/L2/L3/L4/L5 哪一层。
2. **异文查询**：同一章在四文本中的增/删/改/移。
3. **版本谱系**：版本之间的源流与承继。
4. **存疑登记**：无法确定者标 `[归属不确定]`，**禁止默认为 L3**。

## 二、五层归属标签（强制）

```
L1  《滴天髓》经文（京图/刘基系统原文）
L2  刘基原注
L3  任铁樵注（任氏曰）
L4  徐乐吾整理/补注（《订正滴天髓徵义》1935、《滴天髓补註》1937）
L5  后世整理增补（袁树珊撰辑「（新增）」、孙正治白话译注等）
```

## 三、判别流程（落地四步）

1. **看标记**：文中有「任氏曰」→ L3；「原注」→ L2；「（新增）」→ L5；`[注释]/[今译]` → L5（孙译）。
2. **看语体**：清文言（余/此造/夫/是以）→ L3；民国半文半白（吾人/命理学家/民国人物）→ L4；
   现代白话（的/了/是/……就叫做）→ L5。
3. **看内容**：引民国政要（袁世凯/曹锟/李鸿章）→ L4；论神煞纳音为正面 → 徐乐吾系（L4），
   任铁樵**否定**神煞纳音。
4. **兜底**：无任何线索 → 标 `[归属不确定]`，**不得默认 L3**。

## 四、命令

```bash
# 异文查询（三层：L1 经文 / L2 原注 / L3 任氏曰）
python _tools/g04_variant.py     # 产出 _工作/_out/条文异文表.md 与 variants.json

# 归属表（预处理版 + 复核纠偏版）
python _tools/g04_layer.py
python _tools/g04_layer_fixed.py

# 分层标记审计（查漏切）
python _tools/g04_audit_marker.py

# 任徐判别测试集（50 段，二分法守住「不把后世冒认任氏」）
python _tools/g04_testset.py
```

## 五、硬约束

1. **不得把 L4/L5 冒认 L3**；**禁止默认为 L3**。
2. 引任氏原话必须逐字，且能回溯到章节 + 四文本之一。
3. 「（新增）」标记在本工程四文本中**仅 1 处**（TS-04 知命章），不得据他本推演出更多而不注明来源。
4. 四文本 L1 经文**逐字一致率 62/63**，凡报告异文必须给出「基准本 → 对照本」双向原文。
5. 分层块数以**复核后**口径为准（预处理版存在 5 处异形标记漏切 + 9 处「任氏曰」漏切）。

## 六、已知边界

- L4（徐乐吾）底本为**扫描件**（`滴天髓补注-徐乐吾.pdf`，7.9MB），未做全量 OCR；
  L4 样本取自中医古籍出版社 2012 白话本 OCR（质量一般），已在测试集中标注。
- 「袁树珊撰辑本」（240 页扫描件，无文字层）的**全书「（新增）」清单**列为本组待补项。
