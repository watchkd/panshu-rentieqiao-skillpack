# rtq-thought-provenance · 思想溯源技能（第⑥组「审计层」）

## 一、目标

回答一个问题：**哪些是任铁樵继承的、调整的、自己的发挥？** —— 防止**张冠李戴**。

它不进最终命师人格，只做审计：给任氏规则卡标注源流。

## 二、六类标记（强制）

```
【前人已有】     该观点在任氏之前的经典中已明确存在
【任氏继承】     承自前人，任氏基本照搬或收窄
【任氏调整】     承自前人但改换了标准/口径（如把「月令为纲」改为「日主旺衰为唯一标准」）
【任氏明显发挥】 前人无此说，任氏独力主张
【后人发挥】     徐乐吾/袁树珊/现代整理者的文字，误置任氏名下
【归属不确定】   证据不足
```

## 三、溯源靶经典（8 部）

`《渊海子平》《子平真诠》《三命通会》《神峰通考》《穷通宝鉴》《命理探原》《命理约言》《造化元钥》`

## 四、纪律

- **不为制造「任铁樵创新」强行拔高**；古籍早有者明确指出。
- 无法溯源者标 **「未找到来源」**，**不以推测充数**。

```bash
python _tools/g06_rules.py    # 自举规则卡 + 溯源 → _工作/_out/规则卡.json

```
