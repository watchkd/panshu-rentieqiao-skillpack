# 排盘核对说明（v2.4.0「排盘核对层」）

> **一句话**：本包**以用户自己确认过的四柱八字为唯一排盘入口**；排盘工具只作**核对**，
> 不作**定盘**。凡未经用户核对的大运，**一律标「待核」**，不得当作既成事实往下断。

---

## 一、为什么专门立这一层

《滴天髓阐微》任氏断法**处处以大运流年为落点**（元规则 05 六股骨架的第六股就是「系运」）。
排盘一错，后面五股全废——而**大运恰恰是最容易错的一环**，因为它不是「照着生辰查表」，
而是**四重变量叠乘**的结果。故本层把「排盘」从「工具自动完成」改为「**用户确认 + 工具核对**」。

---

## 二、大运四大误差源（逐项）

| # | 误差源 | 错在哪 | 后果 |
|---|---|---|---|
| 1 | **性别** | 大运顺逆由「年干阴阳 × 性别」定：**阳男阴女顺排、阴男阳女逆排** | 性别错/缺 → 整排大运**反向**，一错到底 |
| 2 | **交节边界** | 生于交节当日或前后数小时者，**月柱**可能整体错位 | 月柱是大运起排之基 → 大运**干支全错** |
| 3 | **起运折算** | 起运岁＝「出生时刻 → 最近节」天数，按 3 日折 1 年；各软件「虚岁/周岁」口径亦不同 | 起运差一月乃至一年 → **应期整体平移** |
| 4 | **真太阳时** | 未做经度时差校正时，时柱（乃至临界日日柱）可能整体位移 | 时柱错 → 格局与取用判错（本工具按北京时间排，**不做校正**） |

> 实测：同一生辰（1984-11-12 14:00）**男**作 `丙子→丁丑→戊寅…`（顺），
> **女**作 `甲戌→癸酉→壬申…`（逆）——**仅性别一项，两排大运毫无重叠**。

## 三、本包的执行口径（铁律 11）

1. **首选用户已确认的四柱八字**（连同其排好的大运）；本包**只按已定四柱与大运断命**，
   **不重排、不改盘**。
2. **未给性别** → **不出大运**。只按四柱论原局，并在批语内标「运次待定」。
3. **只给公历生辰** → 可排，但必须：① **先问性别**；② 排出后**回请用户核对四柱与时柱**；
   ③ 大运/起运一律标「**据推，请以你排盘为准**」。
4. **用户提供的大运与工具推算不一致** → **一律以用户为准**；工具结果仅作内部参考，
   **不得回改用户的盘**。
5. **时辰不明** → 按三柱论并标「生时未详」，**同时不出大运**（顺逆与起运皆受时辰影响）。
6. **原书命例未载四柱/大运** → 标「原书未载」，**禁自补**（元规则 03 §二·1）。

## 四、工具用法

```bash
# 依赖：pip install lunar_python   （纯 Python，MIT）
cd <技能包>

# 1) 排盘（四柱 / 节气 / 人元司令 / 大运）
python paipan_tool.py 1984 11 12 14 0 男

# 2) 排盘 + 生成「排盘核对清单」（贴给用户逐项核对）
python paipan_tool.py 1984 11 12 14 0 男 --check

# 3) 不给性别：只出四柱与节气，不出大运
python paipan_tool.py --no-gender 1984 11 12 14 0

# 4) 用户已给四柱：只核顺逆方向，不重排
python paipan_tool.py --four 甲子 乙亥 庚戌 癸未 女
```

**依赖缺失时**：工具直接退出并提示安装；若环境装不上，则**一律改走「请用户提供已确认的四柱与大运」**，
不得凭模型记忆手排大运。

## 五、给用户的标准核对话术（交付前使用）

> 为免排盘偏差，请把你**自己排盘工具里确认过的**四柱八字发我（**连同大运**）。
> 若你只给公历生辰，我会先排一遍请你核对——**尤其时柱与性别**这两项：
> 性别决定大运顺逆，时柱受真太阳时影响，二者一错，整排大运就跟着错。

## 六、与其余层的关系

- **入口协议（主 SKILL §〇）**：第一句就按「四柱优先」索取，本层是其执行细则。
- **论命流水线 P0（rtq-lunming-pipeline）**：P0 输入改为「用户确认的四柱＋大运」优先。
- **岁运推演（rtq-suiyun-tuiyan）**：拿到的大运若标「待核」，其应期断语须同步标「运次待核」。
- **防幻觉三禁（元规则 03 §二）**：本层是「不补盘」在**用户命造**上的延伸——原书命例不补，
  用户命造**也不代定**。
