# 通根查表 · 使用说明（任氏口径机械表 v2）

> 工具：`rtq-panshu/tonggen.py`（生成并可直接查询）
> 数据：`数据/通根查表.json`（120 对：10 干 × 12 支）
> 由 `rtq-quyong-juece`（第②步通根轻重）与 `rtq-shuaiwang-diaodao`（TS-17 有无根）调用。

## 一、为什么需要它

v2.1 把「亥中甲木、未中乙木」断为财星有根，v2.2 却断「木无根」——**同盘两断**。
根因：决策树只给了"长生禄旺重／墓库余气轻"的原则，没有一个可执行、可复验的查表，
取用全靠模型自由裁量。

本表把任氏口径（TS-17-02/03/04）落成机械查表，从根上掐掉这种"两头都能圆"的漂移。

## 二、口径核心

| 档位 | 性质 | 含义（任氏原文依据） |
|---|---|---|
| **重** | 长生/禄/旺 | 四柱通根生旺、富贵之本（TS-17-02"长生禄旺根之重"） |
| **轻** | 墓库/中气/余气/本气 | 墓库即通根、可任财官（TS-17-04"墓库即通根"）；中气余气为旁根 |
| **无** | 无 | 该干在此支不通根 |

- **阳干顺行、阴干逆行**十二长生（通行子平），**不再五行一刀切**：
  - 例：辛（阴）长生在子、旺在申、禄酉；**辛在巳=死地**，不作长生——修正 v1 硬伤。
  - 癸禄子、乙禄卯（阴干禄）→ LQ-06-007「癸通根禄支（子）」对上了。
- **墓库**：甲乙未、丙丁戌、庚辛丑、壬癸辰（TS-17-04 明文）；土四库本身气自根。

## 四、边界与用法（重要）

1. **表只给"两级根力"，不给"有效根"的最终裁定**。上层须合并两条件：
   - **该支是否被冲/穿/合化**破坏（凶）；
   - **该根是否助了忌神**（如 LQ-25-007 丑中辛助庚忌 → 反而根深为祸）。
2. **死地/衰地**（如辛在巳）单看档位为"轻"，但任氏多断其根不足——上层按
   "支于某干为死墓绝 + 无生扶 → 作弱根/无根"处理。
3. **余气**在任氏大部分语境不作有效根（LQ-06-001），仅个别"得地"才认；
   比"中气/本气/墓库"更弱一档。
4. 本工具**不量化打分**（不度日主旺衰百分比）——任氏斥"得时俱旺、失令俱衰"为死法。
5. 调用：`from tonggen import tonggen; tonggen("甲","寅")` → `{"档":"重","性":"禄","五行":"木"}`，
   或直接读 `数据/通根查表.json`。

## 五、与金标准评测的衔接

本表是 `rtq-quyong-juece` 取用的**前置基线**。改表 / 改上层裁定规则后：
1. 重跑 35 个金标命例的取用；
2. `eval.py --pred <本轮预测>` 看用神一致率。
**若某个金标命例的"通根"判定变了而用神飘了，评测会当场点名**——这正是防再漂移的闭环。
