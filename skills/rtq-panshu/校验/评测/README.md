## 一、这是什么

一套**以命例库原文为锚的"用神金标准"**，用于**衡量 + 回归**一次论命流水线（`rtq-lunming-pipeline`）的"取用神"做得对不对。

它解决一个真问题：v2.1→v2.2 同盘两断、结论漂移时，全凭感觉判断"质量升了还是降了"。有了金标准，指标会用数字说话。

## 三、金标准口径（务必遵守，防幻觉）

1. **只认显式词面**：任氏说「以丙火为用」「用神必在午火」「喜其…」「X为病」「全赖…」等，才抽。
2. **隔离否定/泛论/引用**：
   - `俗/旧/所谓/谓/者/或/若/设/则…` 前缀 → 这是任氏**批驳或假设**，不是本命实断，**不采**（例：`俗以丙火为用`、`取火为用者十无一二`）。
   - 引号/括注内（「金水伤官喜火」这类引俗语、它造作比）→ 不采。
3. **gold 门槛**：原文含"用/喜/病/药"任一显式正向信号，且抽取到非空标签。当前 **60 例 gold**；其中**含「用神」者可计分 35 例**。
4. **弱信号（weak，447 例）不入金标**：不用"推测""疑似"词面冒充确证——宁缺毋滥。

> ⚠ 已知边界：原书中"病药/用喜对举"整句圆备者极少（<4%），故金标准以**「用神」单要素**为测评主锚点；全向量（用/喜/忌/病四全）当前 **0 例**，不强求，也不应假造。

## 四、评测口径（eval.py）

- **计分命例** = `state=="gold"` 且含「用」标签者（当前 35 例）。
- **命中判定**：预测「用」五行集合 ∩ 金标「用」五行集合 ≠ ∅ 即算一致。
- **报告**：覆盖率 / 用神一致率 / 逐例误判明细（附金标 evidence 原文）。
- **未覆盖 / 弱标命例不计分**，如实记"未纳入"，杜绝刷分。

## 五、怎么接入日常改造（关键用法）

每次改动技能包（改规则库 / 改 `rtq-quyong-juece` 决策树 / 改 prompt / 升级版本）后：

1. 跑一次流水线对 **35 个金标命例**，把每例的取用结果写成谓词文件：
   ```json
   { "outputs": {
       "RTQ-CASE-LQ-05-010": {"用": ["火"]}
   } }
   ```
2. 评测：
   ```bash
   python eval.py --pred 本次预测.json
   ```
3. **看一致率是否回退**。v2.1→v2.2 那种"同盘财星有根说成无根"的漂移，只要命中这 35 例之一就会在误判明细里被当场点名。
4. 将来若能对全部 60 例 gold 的「喜/病」也逐条喂入，可扩展 eval 的维度（当前先保持「用」单维，稳）。

## 七、命例多维索引（检索面 · 新增）

> 背景：金标准（`build_gold.py`）回答"**这次取用做得对不对**"；多维索引回答"**有哪些原书命例与我这次在断的结构相同**"——前者评正确性，后者找旁证，二者分工互补。它把命例互验从"全文关键词搜"升级为"按维度命中间造"。

### 结构
```json
{ "meta": {"来源":"八字字段日柱+判断依据/任铁樵原断 词面抽取", "n": 494,
           "维度统计": {"日主":461,"寒暖":126,"病":16,"药":94,"格局":96,"日主强弱":185}},
  "entries": {
    "RTQ-CASE-LQ-16-001": {"日主":"水","病":["水"],"药":["火"],"格局":"从儿格", ...},
    ... } }
```
494/508 例至少抽到 1 个维度；**抽不到即缺省，绝不硬造**。

### 抽取口径（防幻觉 ✓）
- **日主**：优先取命例**「八字」字段的日柱**（权威、近全覆盖，非推断）；八字缺失时降级 `日主X/此造X生于` 文本句式。
- **寒暖（调候四态）**：归一到 `{寒,湿,燥,暖}`（寒湿复合保留）。**"寒"仅认调候组合词**（寒金/寒木/寒水/金寒/水冷/寒局…），**排除 贫寒/清寒/寒微/寒儒/寒士/寒门 等贫贱语义**；湿/燥/暖由 湿土/燥土/向阳/炎上/暖 等词面触发。当前值域分布：寒30/湿46/燥33/寒湿6/暖11（共126）。
- **病（命理病方）**：只认 `所忌者X/所嫌者X/ X克Y为病 / X之为病 / 以X为病 / 病在X / 其病在X` 等**判断句式**里的干支/五行方；
  **健康字面病一律排除**（病患/痨病/无灾无病/病愈/疾病/之症）。
- **药（救应）**：`全赖X/喜其X/最喜X/赖X/以X为用/X为用神/取X为用` 后紧邻的干支/五行方。
- **格局（名局线索）**：词面专名细分——从财/从杀/从官/从儿/从势/五专旺(稼穑/曲直/炎上/从革/润下)＋羊刃/建禄/食神制杀/伤官配印/杀印相生/印格/财官/正官。**须成句成词、点得到原文 token**，绝不用单字"从"宽化误标；标注属"格局/名局线索"而非严格分格定论。
- **日主强弱**：词面（`坐禄/得禄`→`得根`；`身弱/无根/虚脱/衰`→`弱`）＋ 八字日柱坐禄查表辅助定`得根`。

**访问接口（`index_query.py`）：**
```python
from index_query import MultiDimIndex
ix = MultiDimIndex()
ix.query(病=["水"], 药=["火"])          # → [CASE_ID,...]  同病同药
ix.query(日主="木", 格局="从格")         # → 同格同日主
ix.groups(("药","日主"), min_size=2)   # → 可互验组合组（当前 8 组）
```
```bash
python build_index.py    # 重建索引
python index_query.py    # CLI 演示检索 + 互验组
```

### 实测（2026-10-09）
- **日主 461/508（91%）**——由「八字」字段日柱权威提取，非文本推断；全局校验（同源于日柱）零错误。
- **寒暖校准为调候四态**（{寒,湿,燥,暖}+寒湿）：剔除原误标——"出身贫寒/一介寒儒/清寒"等**贫贱语义不再误标为寒**；抽查确认寒30 全为"寒金喜火/寒木向阳"等调候寒，湿/燥/暖 全为 湿土/燥土/向阳/炎上 语义。
- **格局已细分**：从财5/从杀8/从官3/从儿10/从势&五专旺共约8/羊刃17/建禄3/财官25/食神制杀3/伤官配印3/杀印相生7/印格2/正官2。抽查从格局与羊刃/财官均为命理取象（如"羊刃当权""财官并旺"），非字面误标。
- 病=水 → 4 例；病=火 → 7 例；病=木 → 2 例。抽查 `LQ-16-001`（壬水为病、以丙火为用 → 病水药火）与 `TS-08-012`（癸水为病、全赖午火 → 病水药火）**病药语义与原文逐字吻合**，无健康病误抓。
- 药×日主 可互验组（≥2 例）达 **19 组**（日主木-药火 10 例、日主火-药火 9 例…）——「命例互验」已可按维度取同造旁证。
- 已知边界：纯十神病方（"以财为病""生煞为病"）无独立干支可依，暂不纳入，宁缺勿滥；格局维度为"名局线索"标签而非严格分格定论。
