### 定位

主 SKILL §三 已列「八步流程」，那是**描述**（告诉大家有哪些步）。本技能是它的**执行契约**——规定每一步**吃什么、吐什么、失败怎么办**，使论命链可复现。

> **边界**：本技能**不做任何命理判断**，只负责**调度**。判断一律下沉到各子技能。
> 本技能**不产命书**——命书由第 7 步（元规则 05 语体）产出。

### 流水线契约（六段·端到端）

```
┌─ P0 排盘定标（v2.4.0 排盘核对层）─────────────────────────┐
│ 输入：**首选 用户已确认的四柱 ＋ 已排大运**                  │
│       （备选：公历生辰 + 性别）                              │
│ 动作：**只按已定四柱与大运定标——不重排、不改盘**（铁律 11）   │
│       · 用户已给大运 → **直接采用**，不另排                   │
│       · 用户未给大运 → 调 paipan_tool.py（**性别必填**）      │
│         参考推算，结果标「运次据推，请以你排盘为准」           │
│       · 顺带定节气、人元司令（仅 12 节定月建）                 │
│ 输出：标准命盘对象 {四柱, 司令, 大运[], 起运, 大运是否已核}    │
│ 失败降级：① 只给四柱 → 跳过节气/大运，标"运次未知"            │
│           ② **性别不明 → 不出大运**，只断原局标"运次待定"     │
│           ③ **时辰不明 → 三柱论，且不出大运**                 │
│           ④ 四柱不全且非原书命例 → **拒绝**，请用户补齐        │
│           ⑤ 原书命例无四柱 → 降"原书叙述层"，禁自补四柱        │
│           ⑥ **用户盘与推算不符 → 以用户为准**，推算仅内部参考  │
├─ P1 归层定标 ────────────────────────────────────────────┤
│ 输入：命盘对象 + 用户所问主题                               │
│ 动作：五层归属定位（L1-L5）；任氏论命**只用 L3**            │
│ 输出：{题域, 命中章[]}                                     │
│ 失败降级：题域不明→按"整体论命"取全章                       │
├─ P2 取用落定 ★枢纽 ──────────────────────────────────────┤
│ 输入：命盘对象                                               │
│ 动作：调 rtq-quyong-juece（六步决策树）+ rtq-shuaiwang-diaodao│
│ 输出：{用神, 喜神[], 忌神[], 病, 药, 格局正变}              │
│ 失败降级：取用不定→**明标"存疑"并举两说**，不得含糊带过     │
│ ⚠ 无此步则 P3/P4 一切论断失其标尺——**必走**                │
├─ P3 主题分诊 + 命例互验 ──────────────────────────────────┤
│ 输入：{题域, 喜忌}                                          │
│ 动作：按主 SKILL §四路由表分流到 17 子技能                   │
│       · 婚姻→rtq-liuqin；官杀→rtq-guansha-shangguan …      │
│       · **先走 rtq-fandui（负向置顶）**                     │
│       · **同造旁证**：MultiDimIndex.query(病/药/格局/日主)  │
│ 输出：各主题断语（各挂 RTQ-RULE）＋ 旁证 CASE_ID[]           │
│ 失败降级：主题无对应子技能→回主 SKILL 通用断法               │
│           无命中旁证→留空，**不硬凑、不编造同造**            │
├─ P4 岁运推演 ────────────────────────────────────────────┤
│ 输入：{原局喜忌, 大运[], 大运是否已核}                       │
│ 动作：调 rtq-suiyun-tuiyan（运序→应期→收口）                │
│ 输出：{运序大势, 关键转折年, 运次是否已核}                   │
│ 失败降级：①大运未知→只在原局层面收口，明标"岁运待补"         │
│           ②**大运为"据推"→应期断语同步标"运次据推，请以你     │
│             排盘为准"**，不得写成既成事实                     │
├─ P5 语体成文 ────────────────────────────────────────────┤
│ 输入：P3+P4 全部断语                                         │
│ 动作：依**元规则 05**六股骨架成文；徐补以「按：」别起         │

│ 失败降级：命例不足→删空例而不编造                           │
└──────────────────────────────────────────────────────────┘
```

### P3 命例互验（多维索引 · 检索面）

> **做什么**：P3 在交各主题断语时，**顺带**用多维索引命中「与我这次所断结构相同」的原书命例，作为旁证随附录交出。**只提供证据，不改变断语**——旁证与断语冲突时，按《失败降级总则》以规则优先、命例标"存疑旁证"。

**接口**（`校验/评测/index_query.py`，数据 `校验/评测/命例多维索引.json`）：

```python
import sys; sys.path.insert(0, r"<技能包>/校验/评测")
from index_query import MultiDimIndex
ix = MultiDimIndex()
ix.query(病=["水"], 药=["火"])        # 同病同药 → [CASE_ID, ...]
ix.query(日主="木", 格局="从格")      # 同格同日主
ix.groups(("药","日主"), min_size=2)  # 可互验组
```

**调用契约**：

| 项 | 规定 |
|---|---|
| 触发时机 | P2 喜忌卡落定后、P3 分诊时（**不得早于 P2**——无喜忌则无维度可查） |
| 查询维度 | 优先 病×药（最强）；次 格局×日主；再次 日主强弱／寒暖 |
| 命中处理 | 取命中 CASE_ID，附「原文锚点」（章号 + 该例 `判断依据`/`任铁樵原断` 首句） |
| 数量 | 每主题 **≤3 例**，宁少勿滥 |
| 无命中 | **留空并写"无同造旁证"**，绝不硬凑、绝不编造同造 |
| 禁止 | 旁证不得改写成断语、不得冒充任氏对本造的原断 |

> **现状**：索引覆盖 **494/508 例**（日主 461／日主强弱 185／寒暖 126／格局 96／药 94／病 16），药×日主可互验组 **19 组**。病维度受语料边界限制（纯十神病方无独立干支），命中率低属正常，**不因"查不到"而放宽口径**。

### 每步交接物（中间产物规范）

| 步 | 产物 | 关键字段 | 下游消费者 |
|---|---|---|---|
| P0 | 命盘 | 四柱／司令／大运／起运／**大运是否已核** | P1,P2,P4 |
| P1 | 题域定位 | 主题／命中章 | P3 |
| P2 | **喜忌卡** | 用神／喜神／忌神／病／药 | P3,P4 ★契约核心 |
| P3 | 主题断语＋旁证 | 断语＋RTQ-RULE＋CONFIDENCE；旁证 CASE_ID[]＋原文锚点 | P5 |
| P4 | 岁运卡 | 运序／转折年 | P5 |
| P5 | 命书 | 正文＋附录 | 交付 |

> **喜忌卡（P2 产物）是整条链的枢纽**——P3 各主题、P4 岁运皆以它为标尺。**P2 未落定，禁入 P3。**

### 失败降级总则

| 情形 | 降级 |
|---|---|
| 四柱不全（非原书命例） | **拒绝**，请用户补齐 |
| 原书命例无四柱 | 降"原书叙述层"，禁自补 |
| **性别不明** | **不出大运**，只断原局，标"运次待定" |
| **时辰不明** | 三柱论 + 标"生时未详"，**且不出大运** |
| **用户盘与推算不符** | **以用户为准**，推算仅内部参考，不回改用户盘 |
| 大运未知 | 只断原局，标"岁运待补" |
| 大运系"据推"（未经用户核对） | 应期断语同步标"运次据推，请以你排盘为准" |
| 取用不定 | 明标存疑，并举两说 |
| 无同造命例 | 删例不编造 |
| 规则与命例冲突 | 规则优先，命例标"存疑旁证" |

### 可复现性要求

1. **每步可追溯**：P0 的排盘**以用户确认的四柱与大运为准**；由脚本推算者须由脚本产出（非手算），并标"据推"；P2-P4 每条断语须挂 `RTQ-RULE-*`。
2. **可审计**：P5 附录须列全部引用规则 ID 与原文行号（附 `SOURCE_FILE`）。
3. **可回环**：P4 发现岁运吉凶反于原局结论时，回 P2 复核取用，不得强断。
4. **不越级**：禁跳过 P2（取用）直入 P3（主题）；禁跳过 P3 直入 P5（语体）。
5. **旁证可核**：P3 交出的每个旁证 CASE_ID，须能用 `index_query.MultiDimIndex().query(...)` 原样复现；附录须给原文锚点，便于人工回查。

### 与主 SKILL 的关系

- 主 SKILL §三「八步」= **描述**；本技能 = **可执行契约**（同样八步，收为六段，加输入/输出/降级）。
- 主 SKILL §四「路由表」= **索引**；本技能 P3 按该表分诊。
- **本技能不取代主 SKILL**——主 SKILL 是总纲起手式（人看），本技能是执行契约（机行）。
