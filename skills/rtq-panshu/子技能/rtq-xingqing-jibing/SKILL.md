# rtq-xingqing-jibing（性情 / 疾病）

> 数据来源：结构化知识库.md（任氏理论组·rtq）。本技能仅呈现任铁樵《滴天髓阐微》原文提炼之规则，严禁混入现代常识。

## 一、入口判定

当求测者问及**性格禀赋、脾气顺逆、身心健康、所患何病、致病之字**时启用本技能。

- 性情类（LQ-24）：先看八字五行是否中和纯粹，偏枯混浊、太过不及者性必乖逆（RULE-01 总纲）。
- 疾病类（LQ-25）：先立五行和则无灾与脏腑干支配属，再察忌神入五脏、客神游六经、木不受水/土不受火等致病之机。
- 二者皆须以**用神所喜、干支气类顺逆**为断，不以神煞、纳音、奇格断性情疾病。

## 二、断法步骤（标 RULE_ID）

- **前置 · 藏干拆解**：断性情疾病前先逐支拆本气/中气/余气、检透干通根与暗藏互冲（总纲第1步）；致病之字多寄于支中藏干（如金水伤官病在火之暗藏、土燥病在木之暗藏），本气为主（RTQ-RULE-TS-08-01 例外）。
- **LQ-24**（第二十四章·性情）：LQ-24性情：先立五行中和/偏枯总纲（RULE-01），再逐气类判定——火（湿土收/金水激）、水（金顺木疏/火土激）、木奔南（水通金或辰土收）、金见水（旺正衰偏）、西水（木纳/土制）、东火（湿土收/转北）、顺逆之机（击神）、从旺从弱（闲神）、阳明/阳浊（郁滞与运）、羊刃伤官用神时支（局格性情）。
  - 证据命例：RTQ-CASE-LQ-24-001、RTQ-CASE-LQ-24-004、RTQ-CASE-LQ-24-006、RTQ-CASE-LQ-24-009、RTQ-CASE-LQ-24-011、RTQ-CASE-LQ-24-013、RTQ-CASE-LQ-24-015、RTQ-CASE-LQ-24-017、RTQ-CASE-LQ-24-019、RTQ-CASE-LQ-24-021、RTQ-CASE-LQ-24-025
- **LQ-25**（第二十五章·疾病）：LQ-25疾病：先立五行和则无灾与脏腑干支配属（RULE-01），再论血气乱（心肾相交/相战）、忌神入五脏（阴浊深伏+有余不足）、客神游六经（表病）、木不受水/土不受火（各季受克宜忌）致血病气伤，最后金水伤官/火土印绶/木火/郁火金/土燥土虚具体病证，并诫不可专执当通人事。
  - 证据命例：RTQ-CASE-LQ-25-001、RTQ-CASE-LQ-25-004、RTQ-CASE-LQ-25-007、RTQ-CASE-LQ-25-009、RTQ-CASE-LQ-25-012、RTQ-CASE-LQ-25-014、RTQ-CASE-LQ-25-016、RTQ-CASE-LQ-25-021

### LQ-24·第二十四章·性情

#### RTQ-RULE-LQ-24-01 ［任铁樵·C］
- **章**：LQ-24
- **任氏原文**：赋于人者，须要五行不戾，中和纯粹，则有恻隐、辞让、诚实之情；若偏枯混浊，太过不及，则有是非、乖逆、骄傲之性矣。
- **规则提炼**：性情由五行之戾/和、偏枯/中和决定：八字五行中和纯粹者，性具恻隐、辞让、诚实之情；偏枯混浊、太过不及者，性具是非、乖逆、骄傲之性。
- **条件**：五行中和纯粹（不戾）=> 中和之性；偏枯混浊、太过不及 => 乖逆之性。
- **例外**：无（任氏以五气先天洛书之气为判，未见例外）。
- **次序/位置**：性情判定总纲，居章首。

- **规则提炼**：火燥烈者，唯可用湿土（丑、辰）润收其烈，则知礼、成慈爱之德；若以金水激之，则火势更烈、不知礼而生灾祸。

- **规则提炼**：水势冲奔（旺极）者，逆之以火土则更刚；顺之以金（顺势）、木（疏淤）则性反柔，智巧多能而不失仁义。

- **规则提炼**：木奔南方泄气太过：有金须水以通之，无金须辰土以收火气，则为人恭而有礼、和而中节；若无水济土、土以晦火，发泄太过，则聪明自恃、迁变不常、成妇人之仁。

#### RTQ-RULE-LQ-24-05 ［任铁樵·C］

#### RTQ-RULE-LQ-24-07 ［任铁樵·C］
- **章**：LQ-24
- **任氏原文**：东方之火，火逞木势，其炎上之性，不可御也，只可顺其刚烈之性，用湿土以收之，则刚烈之性，化为慈爱之德矣。一转北方，焉制焚烈之势？必刚暴无礼。若无土以收这，仍行火木之运，顺其气势，亦不失慈让恻隐之心矣。
- **规则提炼**：东方之火用湿土收之 => 刚烈化为慈爱；一转北方（水）=> 刚暴无礼；若无土仍行火木运顺势 => 亦不失慈让恻隐之心。

- **例外**：无土可收时，仍行火木之运顺势亦不失慈让。

#### RTQ-RULE-LQ-24-08 ［任铁樵·C］
- **章**：LQ-24
- **任氏原文**：顺则宜顺，逆则宜逆，则和平而性顺矣。如木旺得火以通之，顺也；土以行之，生也，不宜见金水之击也。木衰，得水以生之，反顺也；金以助水，逆中之生也，不宜见火土之击也。我生者为顺，生我者为逆；旺者宜顺，衰者宜逆，则性正情和。如遇击神，旺者勇急，衰者懦弱。
- **规则提炼**：顺逆之机：我生者（旺）宜顺，生我者（衰）宜逆；旺者遇击神则勇急，衰者遇击神则懦弱。岁运遇击神亦能变为强弱。
- **条件**：旺者宜顺（我生者）、衰者宜逆（生我者）；遇击神：旺者勇急、衰者懦弱。
- **例外**：格局得顺逆之序者性本和平，至岁运遇击神亦能变为强弱（宜细究）。
- **次序/位置**：顺逆之机总断，论击神之变。

- **章**：LQ-24
- **任氏原文**：逆则宜逆，顺则宜顺，则性正情和矣，如木旺极得水以生之，逆也；金以成之，助逆之生也，不宜见己丑之闲神也。如木衰极，得火以行之，反逆也；土以化之，逆中之顺也，不宜见辰未闲神也。此旺极衰极，乃从旺从弱之理，非前辈旺衰得中之意。如旺极见闲神，必为狂猛；衰极见闲神，必为姑息。岁运见之亦然，火土金水如之。
- **规则提炼**：从旺从弱（旺极衰极）之理：旺极不宜见闲神（己丑）=> 狂猛；衰极不宜见闲神（辰未）=> 姑息。岁运见之亦然。此非前辈旺衰得中之意。
- **条件**：旺极见闲神(己丑) => 狂猛；衰极见闲神(辰未) => 姑息；岁运同。
- **例外**：旺极衰极乃从旺从弱之理，非旺衰得中之意。
- **次序/位置**：从旺从弱判定，论闲神之害。

### LQ-25·第二十五章·疾病

#### RTQ-RULE-LQ-25-01 ［任铁樵·C］
- **章**：LQ-25
- **任氏原文**：凡一脏配一腑，腑皆属阳，故为甲、丙、戊、庚、壬；脏皆属阴，故为乙、丁、己、辛、癸。或不和，或太过不及，则病有风、热、湿、燥、寒之症矣……若强制旺神，寡不敌众，触怒其性，旺神不能损，弱神反家伤矣。是以旺神太过者宜泄，不太过宜克；弱神有根者宜扶，无根者反宜伤之。凡八字须得一神有田力，制化合宜，主一世无灾。
- **规则提炼**：五行和者一世无灾。和者贵在泄其旺神、补其不足之弱神：旺神太过宜泄，不太过宜克；弱神有根宜扶，无根反宜伤；强制旺神则触怒其性、弱神反伤。脏腑配干支：脏阴乙丁己辛癸（肝心脾肺肾），腑阳甲丙戊庚壬。
- **条件**：八字得一神有力、制化合宜 => 一世无灾；强制旺神 => 弱神反伤而病。
- **例外**：非全而不缺为美、生而不克为和；要贵在泄旺补弱。
- **次序/位置**：疾病总纲，先立五行和则无灾、脏腑配属。
- **关联命例**：RTQ-CASE-LQ-25-001、RTQ-CASE-LQ-25-002、RTQ-CASE-LQ-25-003

#### RTQ-RULE-LQ-25-02 ［任铁樵·C］
- **章**：LQ-25
- **任氏原文**：血气乱者，五行悖而不顺之谓也。五行论水为血，人身论脉即血也。心胞主血，故通手足厥阴经，心属丁火，心胞主血，膀胱属壬水。丁壬相合，故心能下交于肾，则丁壬化木，而神气自足，得既济相生，血泳流通而无疾病矣。故八字贵乎克处逢生，逆中得顺而为美也。若左右相战，上下相克……此五行颠倒相克之理，犯此者，必多灾病。

## 五、失效场景

- 求测者只报公历生日但未校正真太阳时、未定四柱，无法定五行中和偏枯者，本技能不可用。
- 原书 OCR 难辨、四柱不全之造（如仅记日干与月令者），只能据条文作趋势推断，不可断具体性情疾病。
- 任氏明言不可专执「当通人事」论病（LQ-25），若脱离干支气类、单凭人事揣测病证，属失效。
- 以神煞（如桃花咸池论邪淫）、纳音、奇格异局断性情疾病者，一律不取（见 rtq-fandui）。
