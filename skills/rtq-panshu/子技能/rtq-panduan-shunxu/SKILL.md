# rtq-panduan-shunxu（判断次序总纲）

> 数据来源：结构化知识库.md（任氏理论组·rtq）。本技能呈现任铁樵实际推理次序，**断盘前置步骤**。仅据任氏原文提炼，严禁混入现代常识。

## 一、任氏全局推理次序总纲

综合各章反推，任氏断一盘之次序可归纳为五步，环环相扣、不可乱序：

1. **先月令定旺衰**——以月令（提纲）为枢，定五行当令与不当令、旺衰之基。
   - 引用：`TS-03 人道`（先辨干支顺悖，再审四柱是否流通、五行是否偏枯，终以中和定贵贱）；`TS-06 配合`（先就四柱干支究衰旺喜忌）；`TS-10 形象`（先分两气成象/五气成形）。
   - 证据命例：RTQ-CASE-TS-03-001、RTQ-CASE-TS-06-001、RTQ-CASE-TS-10-*（见各章次序规则）。
2. **察日主强弱**——于月令旺衰之上，察日主本身的强与弱、衰与旺。
   - 引用：`TS-04 知命`（再审日主衰旺顺逆：察衰旺、究顺悖、审进退、论喜忌）；`TS-09 干支总论`（天覆地载，干支互为根荫定日主依托）。
   - 证据命例：RTQ-CASE-TS-04-001、RTQ-CASE-TS-04-003、RTQ-CASE-TS-04-004。
3. **审气势顺逆**——辨干支之顺悖、五行之流通、形象之专旺或全缺、局中制化。
   - 引用：`TS-08 地支`（以强弱喜忌定冲之吉凶，得令冲衰则拔、失时冲旺无伤）；`TS-11~TS-15`（干支、地支、形象、方局、八格之气势顺逆）；`LQ-24 性情`（顺逆之机、从旺从弱）。
   - 证据命例：RTQ-CASE-TS-08-*、RTQ-CASE-TS-10-* 等。
4. **定用神**——以「用神」为枢，不拘十神名目美恶，当抑则抑、当扶则扶（去留舒配）。
   - 引用：`TS-04 知命`（立用神为枢，不用则尽可劫伤）；`TS-06 配合`（定用神不拘十神名目美恶，当抑则抑当扶则扶）；`TS-16~TS-22`（用神、真假、虚实、清浊、真假寒暖燥湿等）。
   - 证据命例：见各章次序规则。
5. **断事**——用神既立，方论性情、疾病、出身、地位、岁运、六亲等具体事象。
   - 引用：`LQ-24~LQ-29`（性情疾病、出身地位岁运贞元皆在用神既立之后展开）；`TS-23~TS-34`（六亲、富贵贫贱、恩怨、生死等依用神而断）。
   - 证据命例：见各章次序规则。

> 次序铁律：任氏明言「不论日主之衰旺，总以财官为喜」与「不管日主之强弱，尽以食印为福」皆属误区（见 rtq-fandui），必先于定用神前排除。
