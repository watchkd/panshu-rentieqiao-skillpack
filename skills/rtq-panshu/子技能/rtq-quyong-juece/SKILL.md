### 入口判定

拿到八字（四柱已定），凡须回答下列任一问，进入本技能：

1. **用神是什么**（"这个八字用什么""喜神是什么"）者；
2. **格局成破**（"什么格""成格还是破格"）者；
3. **喜忌如何**（"喜什么忌什么""哪个字是病"）者；
4. **从化与否**（"是不是从格""该不该从"）者。

> **边界**：本技能**只到"用神落定＋喜忌清单"为止**，不及其余主题（婚姻／六亲／疾病各归其子技能）。
> 本技能是 **`rtq-suiyun-tuiyan` 的前置**——无喜忌标尺则岁运无从断。凡须论岁运者，必先走本技能。
> **不量化打分**：日主强弱按任氏"得时不旺／失时不弱"定性判，**不给日主算分数**（与 `rtq-shuaiwang-diaodao` 一致）。

### 六步决策树

```
① 月令取格
   ├─ 月令人元司令为何神？ → 透干否？
   │    ├─ 透 → 据此取格
   │    └─ 不透 → TS-12：若月令为禄刃/无格可依，则另寻他支透干者取格
   └─ 月令本气透干 → 正格（八格：官/杀/财/印/食/伤/禄/刃）
        └─ 成格？破格？ → 入 ③ 病药
② 日主强弱（定性，不量化）
   ├─ 得时不旺（春木遇重金之类）
   ├─ 失时不弱（秋木得深根之类）
   └─ 以四柱通根轻重定（长生禄旺重 / 墓库余气轻）——见 rtq-shuaiwang-diaodao
③ 病药识别 ★任氏第一抓手
   ├─ 孰为"病"？——破局之一字（克破相神、夺我用神者）
   └─ 孰为"药"？——救应之神（能去病、能通关、能生扶用神者）
④ 用神落定（四路择一）
   ├─ 扶抑：日主过强/过弱则抑之/扶之
   ├─ 通关：两神相战，取通关之神
   ├─ 调候：冬夏寒暖燥湿失衡，取调候之神（火暖／水润）
   └─ 从化：日主无根而从／合而化
④A 取用对抗证伪 ★家法（强制）：撞俗论→破俗论→自证所取（写被否次优用神+理由）
   任氏语式「以俗论之/初看/似乎/不知/殊不知」→点破真相。未做则第④步不完。
⑤ 喜忌校验
   ├─ 喜神辅弼（LQ-05-26）：喜用皆有精神 → 局佳
   ├─ 忌神有无制化？——无制则凶倍
   └─ 闲神：不助喜不助忌，与喜合则化喜、与忌合则化忌（LQ-01-17）
⑥ 正变判定
   ├─ 正格成立 → 用神即 ④ 所定
   └─ 正格不成立（日主无根／满盘一神）→ 论从化：从财/从官/从儿/从势/专旺
        └─ 假从：微根未净 → 行运去根则真
```

### 各步断法细目

#### 第①步 月令取格

1. **先取月令人元司令**（须由 `paipan_tool.py` 定，**禁凭印象**）：如亥月戊土→甲木→壬水三日分司。
2. **透干取格**：司令之神透于干，即以此神取格。
3. **无格可依（TS-12）**：月令若为**禄刃**（比劫）则**不取格**（禄刃非用神），另寻他支透干者取格；四柱俱无透，则取**月令本气**为体，别论。
4. **格局成败**：看相神（护格之神）有无、忌神有无制化——入第③步病药。

#### 第②步 日主强弱（定性）

- **通根必查表**（`tonggen.py` / `数据/通根查表.json`，**禁凭印象**）：对百日干及当令/财官之星，
  逐一看其在四支的根力：
  - 重（长生/禄/旺）＝根深；轻（墓库/中气/余气）＝根浅；无＝无根。
  - 须再交语境：该支若被冲/穿/合化，或所助为忌神，则"有效根"降档甚至作无根
    （LQ-25-007 丑中辛助庚忌反为深根；LQ-06-006 丁中气被丑未冲则虚脱）。
- **通根轻重**：长生禄旺＝根之重（甲乙逢亥寅卯）；墓库余气＝根之轻。
- **得时不旺／失时不弱**（TS-17）：春木遇重金虽当令亦危；秋木得深根虽失令亦强。
- **干多不如根重**：天干三比肩，不如地支一根气。

#### 第③步 病药识别 ★

任氏论命，**首重"病"**（508 例中"病"字 114 见）。断法：

1. **寻病**：命局中**破局之一字**——克破相神者、夺我用神者、生助忌神者。
   - 例：「所忌者，年干癸水克时干丁火为病」（LQ-01-001）。
2. **寻药**：能**去病**、能**通关**、能**生扶用神**之神。
   - 例：「全赖月干乙木通根，泄水生火，此喜神即是财星也」（同上）。
3. **病深病浅**：病在干易去、在支难去；病得制则浅、无制则深（"为病甚浅"）。
4. **药须有力**：药无根，则病虽显而莫能救。

#### 第④步 用神落定（四路）

| 路 | 判据 | 取神 |
|---|---|---|
| **扶抑** | 日主过强／过弱 | 抑之（克泄耗）／扶之（生助） |
| **通关** | 两神相战（如财印相战） | 取中间通关之神 |
| **调候** | 冬夏寒暖燥湿失衡 | 冬取火暖、夏取水润 |
| **从化** | 日主无根而从、或合而化 | 从其旺神／化神为用 |

> **择路次第**：任氏法以**病药为先**——有病先治病，病去而后论扶抑调候；无病乃论调候（寒暖）与扶抑。

#### 第④·A步 取用对抗证伪（家法制度化，任氏第一习惯）★

任氏取用，必先撞一次"俗论"再反手点破——这是他断命的第一修辞，也是防取用漂移的**强制自检**。取用落定一字前，**必须显式完成两次对抗**（任氏语式「**以俗论之/初看/似乎/不知/殊不知**」→ 点破真相）：

1. **撞俗论**：先自问"若以俗眼（月令独看、杀印相生、金水双清作贵、以财官为命）会怎么取？"——写出一句俗议。
2. **破俗论**：再点破它为何失实（任氏实证句式）：
   - 「不知亥子当权，冲坏印绶，天干火土虚脱」（LQ-03-15）
   - 「初看似佳美…不知财官虽可养命，必先日主旺相能任」（LQ-05-18）
   - 「以俗论之，两干不杂，金水双清，定为贵格…不知气浊神枯」（LQ-05-48）
3. **自证所取**：说明为何取甲非乙——写下**被否掉的次优用神及证伪理由**，任氏自证式：
   - 「用火敌寒，所忌者癸水克丁，全赖乙木通根泄水生火」（LQ-01-001）
   - 「不知木旺自能生火，则丁反不从壬化木…岁运须逢水」（LQ-15-07）

**规则**：凡取用未"撞&破俗论"、未写"被否次优用神及理由"，即视作**未完成第④步**，不得进入喜忌校验与岁运——落定一字且自证，防"两头都能圆"。

#### 第⑤步 喜忌校验

1. **喜神辅弼**（LQ-05-26）：用神之外须有喜神辅之，"喜用皆有精神"则局佳、"喜用两伤"则败。
2. **忌神制化**：忌神有制则减凶、无制则凶倍。
3. **闲神**：不助喜忌者为闲神；**闲神与喜神合则化为喜、与忌神合则化为忌**（LQ-01-17）。
4. **喜忌齐备**：须**明列**喜神清单与忌神清单，方入岁运。

#### 第⑥步 正变判定

- **正格成立**（有格可依且成）→ 用神为第④步所定。
- **正格不成立**（日主无根、满盘一神）→ 论**从化**：从财／从官／从儿／从势／专旺。
- **假从**：微根未净，为"假从"；行运**去其微根**则应真，应吉；运助微根则反局应凶。

### 规则集

#### RTQ-RULE-TS-12-01（月令取格与禄刃）［L3-任铁樵·A］
- **要义**：取格以月令人元司令透干为准；月令为禄刃（比劫）者**不取格**，另寻他支透干。
- **触发**：月令取格
- **例外**：四柱俱无透干，则以月令本气为体

#### RTQ-RULE-LQ-05-26（喜神辅弼）［L3-任铁樵·A］
- **要义**："喜用皆有精神"则局佳；"喜用两伤"则败。用神须有喜神辅弼。
- **触发**：喜忌校验
- **关联命例**：多例（"喜用齐来 → 宦途顺遂"）

#### RTQ-RULE-LQ-01-17（闲神化喜忌）［L3-任铁樵·B］
- **原文**：喜财而财合闲神：化财得妻财，化忌神主妻有外情。
- **要义**：闲神本身中性，**与其合者之属性**定其吉凶——闲神合喜则化喜、合忌则化忌。
- **触发**：闲神论断、合化

#### RTQ-RULE-LQ-01-01（星位与喜忌顺序）［L3-任铁樵·C］
- **要义**：先定星位，再论衰旺喜忌（判断顺序）。**顺序不可倒置**。
- **触发**：一切十神论断之序

#### RTQ-RULE-LQ-24-N01 / LQ-05-48 / LQ-05-18（取用对抗证伪）［L3-任铁樵·A］★
- **原文**（列证）：
  - LQ-24-N01：「**俗以丙火为用**，运逢火土为佳，**不知金水同心，可顺而不可逆**。」
  - LQ-05-48：「**以俗论之**，两干不杂，金水双清，定为贵格…**不知气浊神枯**。」
  - LQ-05-18：「**初看似佳美**…**不知**财官虽可养命，必先日主旺相能任。」
- **要义**：任氏取用第一习惯——**先撞俗论（月令独看／杀印相生／双清作贵／以财官为命）再反手点破**。这是"落定一字且自证"的家法，防取用漂移（v2.1财星有根 vs v2.2无根的"两头能圆"即反面）。
- **流程**（第④·A步）：撞俗论一句 → 破俗论一句（"不知/殊不知"）→ 自证所取：写被否掉的次优用神及证伪理由。
- **强制**：未完成对抗三步者，视作第④步未完成，不得入喜忌校验与岁运。
- **触发**：取用落定前（每次必做，不特判触发）

#### RTQ-RULE-LQ-15-07（丁壬合化之对抗）［L3-任铁樵·B］
- **原文**：「如丁壬之合，日主是丁，生于春令，壬水无根，必从丁合，**不知木旺自能生火，则丁反不从壬化木**。」
- **要义**：合化亦须对抗——俗见"壬水无根必从丁合"，任氏破为"木旺自能生火则丁不从化"。**被否判定（不从化）须给证伪理由。**
- **触发**：合化论用、化气成否

### 逐字锚例（取用范本）

> **例一·以"泄水生火"为药（LQ-01-001）**
> 八字：癸卯 乙丑 庚申 丁丑
> 原断：「此造寒金坐禄，印绶当权，**足以用火敌寒**。**所忌者，年干癸水克丁为病**，**全赖月干乙木通根，泄水生火，此喜神即是财星也**。」
> **析**：用火（调候抗寒）→ 寻病（癸水克丁）→ 取药（乙木泄水生火）。**病药路径全显。**

> **例二·用神一字定之（LQ-05 诸例）**
> 原断：「**用神一字定之**，喜用齐来 → 宦途顺遂」；「喜用两伤 → 不禄」。
> **析**：任氏取用，务在"一字定之"——不游移。喜用俱到则吉，俱伤则凶。

> **例三·取用对抗（LQ-24-N01，俗主观 vs 任氏破）**
> 原断：「**俗以丙火为用**，运逢火土为佳，**不知金水同心，可顺而不可逆**，须逢木运，生化有情，可免凶灾。」
> **析**：①撞俗论（俗取丙火）→ ②破俗论（不知金水同心）→ ③自证（须木运生化）。**对抗三步全显。**

### 输出范式

取用段须**显列五事**（但按元规则 05 语体成文，非清单）：

1. **定格**：月令何神司令、透否、成何格；
2. **日主**：得时／失时、根之轻重（定性一句）；
3. **病药**：孰为病、孰为药、药有力否；
4. **用神与喜忌**：用神某字，喜某字某行，忌某字某行；
5. **对抗自证**：撞俗论一句 + 破俗论一句 + 被否次优用神及理由一句（第④·A步）。

> 范句：「此造（月令某神司令），（日主定性）。**以俗论之，**（俗议一句），**须知**（点破真相一句）。**所用者某也**，（一句言其理）；**不用某者**，以（某病某忌）故也。**所忌者某也**，（一句言其为病）。**喜神某也**，（一句言其辅弼）。行运喜某忌某。」
> **禁**：给日主"打分"；**禁**罗列评分表；**禁**含糊"综合来看用神不明"——任氏取用**必落定一字**，落不定者，明标"存疑"并举两说并各自证伪。
