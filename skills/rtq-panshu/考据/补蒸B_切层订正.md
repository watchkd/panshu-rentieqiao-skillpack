## 二、缺陷成因（机制）

公共地基的切层实现依赖**形如 `^(原注：|任氏曰：)` 的行首匹配**。该模式有两个盲区：

1. **只认全角冒号 `：`** → 遇到全角分号 `；`（`任氏曰；` / `原注；`）时不视为块边界
2. **只认「曰」字** → 遇到误字「任氏日」时不视为块边界

一旦错过边界，`任氏曰` 整块会被**并入其前一个块**（通常是原注块）。因此产生的后果不是"少了一个标记"，而是：

- 该块**整块文本被错挂到 L2（原注/刘基）名下**
- 前一原注块被**从中间截断**再拼接后文（`layerd_chapters.json` 中的原注块尾部出现明显的不连贯）
- 若是**整章唯一的任氏曰**，则整章 L3（任铁樵注）**归零**

> 这正好解释了 63章清单中 `TS-17 衰旺 = 0` 与 `LQ-04 兄弟 = 0` 两处"任氏曰块数: 0"的异常。该异常**不是原书没有任氏曰，而是切层缺陷**。

## 五、修正版切层正则（供总装采用）

> 依硬约束：**不修改公共地基文件本身**，本正则单独输出，供总装采用。

### 5.1 推荐正则

```python
import re

# 【修正版 · 块边界标记】
# 覆盖六种形态：原注：/ 原注；/ 任氏曰：/ 任氏曰；/ 任氏日：/ 任氏日；
MARK_RE = re.compile(r'(原注|任氏[曰日])\s*[：:；;]')

# 若需要行首锚定（与公共地基原实现风格一致），用：
MARK_LINE_RE = re.compile(r'(?m)^\s*(原注|任氏[曰日])\s*[：:；;]')

# 归属层判定
def layer_of(mark: str) -> str:
    """'原注…' -> yuanzhu(L2)；'任氏曰…'/'任氏日…' -> renshi(L3)"""
    return 'yuanzhu' if mark.startswith('原注') else 'renshi'
```

### 5.2 与旧正则的差异

| 项 | 旧正则 | 修正版 |
|---|---|---|
| 全角冒号 `：` | ✅ | ✅ |
| **全角分号 `；`** | ❌ **漏** | ✅ |
| 半角冒号 `:` / 半角分号 `;` | ❌ | ✅（防御性） |
| **误字「任氏日」** | ❌ **漏** | ✅ |
| 标记后空格 | ❌ | ✅（`\s*`） |

### 5.3 切块示例实现

```python
def split_layers(text: str) -> list[dict]:
    """按修正版正则切分经文/原注/任氏曰三层"""
    import re
    text = re.sub(r'[\s\u3000]+', '', text)          # 空白无关
    marks = list(MARK_RE.finditer(text))
    out = []
    if not marks:
        return [{'layer': 'jing', 'text': text}]
    if marks[0].start() > 0:
        out.append({'layer': 'jing', 'text': text[:marks[0].start()]})
    for i, m in enumerate(marks):
        st = m.start()
        en = marks[i + 1].start() if i + 1 < len(marks) else len(text)
        out.append({'layer': layer_of(m.group(1)), 'text': text[st:en]})
    return out
```
