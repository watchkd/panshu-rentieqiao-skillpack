## 一、口径定义（本报告统计的是什么）

同一本《滴天髓》在不同版本、不同程序口径下，"命例有多少"会得到完全不同的数字。先把口径钉死：

| 口径编号 | 口径名称 | 判定规则 | 数据源 |
|---|---|---|---|
| **K1** | 笺订本"此造"指称口径 | 正文中出现「此造」二字的次数（含历代注家引用、序跋、校勘记） | 笺订 上·中·下 |
| **K2** | 笺订本完整四柱行口径 | 独立成行的「四柱（年月日时）」命例块 | 笺订 上·中·下 |
| **K3** | 通行本锚点口径 | 正文内联干支串（≥4 干支）+ 独立干支短行（大运序列）的**程序锚点**总数 | 完美排版（=阐微本） |
| **K4** | 通行本完整四柱口径 | 含完整四柱（4 柱）的干支行簇 | 完美排版（=阐微本） |
| **K5** | 03 组人工裁切口径 | K3 锚点经人工按「四柱＋六字大运」裁切、去重后的**真实命例数** | `命例锚点底账.md` 上游 |

## 三、"512 例 vs 480 例"口径结论（★核心结论）

**结论：**

> **"512 例"是《滴天髓阐微》通行本（袁树珊校勘本 → 李雨田增订本系统，即本组"底本对照\_完美排版.txt"所据文本）的"完整四柱"排盘口径；本组程序实测为 510 例，与网络流传的 512 例吻合（差 2 例系原文本断行/换行差异）。**
> **它统计的是"书里能数出多少个八字"，且包含历代整理者掺入的命例，不是任铁樵本人的命例数。**

**版本依据（逐条）：**

| 项 | 证据 |
|---|---|
| 版本归属 | 完美排版底本 = 《滴天髓阐微》任铁樵注本。袁树珊民国二十二年（1933）据海宁陈氏藏蒋汝蘋钞本取名《阐微》影印；民国三十六年（1947）李雨田增订重排，"是为任铁樵注本最流行的版本"（见笺订上·校订序）。网络流传的"512 例"正是数这个流行本 |
| 程序复现 | 完美排版干支行簇 = **627**（与底账 627 一致）；其中含完整四柱的簇 = **510** |
| 与 480 的关系 | 627 → 480 的落差 = 03 组人工把"内联干支串"误切、把"大运序列"并簇、把重复命例合并后得到；两次口径**不是同一层级**：480 是**命例实体数**，510/512 是**排盘出现次数（含跨版本重复与后世掺入）** |
| 反证 | 笺订本（含钞稿本、勘定增注本等更接近任氏原稿的版本）完整四柱仅 **592 行 / 453 个不同八字**，远低于 510，说明"512"并非任氏原著的命例总数，而是**通行本排盘口径** |

**一句话对答：**
- 有人问"《阐微》里有多少命例" → 答 **510~512**（通行本完整四柱排盘口径，含后世掺入）。
- 有人问"任铁樵原著有多少命例" → 答 **≤480**（03 组人工裁切口径），且**真正能确证为任氏亲验的（可信度 A）远少于此**。
- 有人问"笺订本有多少命例" → 答 **612 处「此造」指称 / 453 个不同八字**，两者都不是"任铁樵命例数"。
