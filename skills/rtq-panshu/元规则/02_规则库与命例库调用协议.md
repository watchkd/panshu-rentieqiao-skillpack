# 元规则 02 · 规则库与命例库调用协议（v2.0 双层）

> 本包判断的依据是三个数据文件（v2.0 双层版）。协议统一，避免随手编造。

## 一、规则库 `数据/规则库_1538_双层.json`

**1538 条 = L3 任注 797 ＋ L4 徐补 741**，按 `AUTHOR` 分区；每条含统一 schema：

| 字段 | 含义 |
|------|------|
| `RULE_ID` | 规则卡 ID。`RTQ-RULE-<章>-<序>` 为 **L3 任注**（`-N\d+` 为任氏反对的负向规则）；`RTQ-RULE-XLW-<章>-<序>` 为 **L4 徐补** |
| `CHAPTER_ID` | 章节号 `TS-xx` / `LQ-xx`（63 章体系，两层同键对齐） |
| `AUTHOR` | 归属层：`L3` 任铁樵 / `L4` 徐乐吾 |
| `TEXT` | 原文逐字摘录 |
| `RULE` | 规则（负向规则为反对对象） |
| `CONDITION` / `EXCEPTION` | 触发 / 例外 |
| `ORDER` | 判断次序 |
| `CASE_IDS` | 关联命例 |
| `CONFIDENCE` | A 抽检命中 B 通过 C 存疑 |
| `NEGATIVE_RULE` | 是/否（负向规则） |
| `DISPUTED` | 任徐分歧（`任断→徐断`，仅 L4 卡可能有值） |

**用量**：断某主题 → 先按 `CHAPTER_ID` 定位所属章 → **双层并出**（L3 任说 + L4 徐补）→ 按 `ORDER` 依序读规则 → 命中即挂 `RULE_ID` 引用。**同一主题规则按 ORDER 排序读，不可跳序曲解。断"任氏怎么论"只取 `AUTHOR=='L3'`。**

## 二、命例库 `数据/命例库_712_双层.json`

**712 例 = L3 任氏 508 ＋ L4 徐氏 203 ＋ L5 后世 1**，按 `LAYER` 分区。

- **L3 任氏命例**：19 契约字段（CASE_ID / CHAPTER_ID / LAYER / ADDED_BY_EDITOR / SELF_REFERENCE / 八字 / 大运 / 性别 / 身份 / 出身 / 职业 / 人生事件 / 流年与应期 / 任铁樵原断 / 判断依据 / 所用规则 / 最终结论 / 版本差异标志 / 可信度）。
- **L4 徐氏命例**：契约字段 ＋ 徐氏专用（`徐乐吾补注` / `任铁樵原断` / `已由任氏收录` / `互参` / `DUPLICATE_OF_L3`）。

**可信度**（L3）：A 任氏自述亲验 → B 有明确来历时地 → C 来源不明 → D 有时代/人物考证问题。引用时若为 C/D，须注明存疑。

**引用协议**：
- 引用命例必须给 `CASE_ID`；L4 命例给 `RTQ-CASE-XLW-…`。
- **任徐同造 12 例**（见 `数据/xlw_L4-L3互参表.json`）：只标互参、双向给 ID，不重录。
- **必须声明"已知结局，事后反推"的局限**——命理典籍命例多为"先知道结果再套理论"，不得把命例应期当作可外推的必然。
- 命例做佐证，不做唯一依据；同主题应优先以规则结论为准、命例辅证。

## 三、归属库 `数据/归属库_五层v2.json`

63 章 × 五层块，供原文逐字溯源。某规则要回原文，按 `CHAPTER_ID` → 归属库该书章 → `blocks[]` 中对应 `LAYER` 块：
- `LAYER=='L3'` → 任氏注原文
- `LAYER=='L4'` → 徐乐吾补注原文（带 `SOURCE_LINE` 底本行号）
- `LAYER=='L5'` → 孙正治注释·今译

## 四、章号基准

全项目章号以 `TS-01…TS-34`（通神论）+ `LQ-01…LQ-29`（六亲论）为准，禁止另起编号。规则→章、命例→章、归属→章三表共享同一 `CHAPTER_ID`，互查零悬空（已机械校验）。**L4 徐补沿用同一章号体系**，故与 L3 可同键双层检索。

## 六、命例多维索引 `校验/评测/命例多维索引.json`（v2.3 新增 · 检索面）

规则库/命例库回答"原文怎么说的"；**多维索引回答"有哪些原书命例与我这次所断结构相同"**——它是第 6 步「命例互验」的检索入口，取代原先的全文关键词搜。

| 维度 | 覆盖（/508） | 抽取口径 |
|---|---|---|
| 日主 | 461 | 取命例「八字」字段日柱（权威，非推断） |
| 日主强弱 | 185 | 词面（坐禄/得禄→得根；身弱/无根/虚脱→弱）＋ 日柱坐禄查表 |
| 寒暖 | 126 | 调候四态 {寒,湿,燥,暖}；**排除贫寒/清寒/寒儒等贫贱语义** |
| 格局 | 96 | 名局线索（从财/从杀/从儿/专旺/羊刃/建禄/财官…），非严格分格定论 |
| 药 | 94 | 全赖/喜其/最喜/以X为用 后紧邻干支/五行 |
| 病 | 16 | 仅命理病句式（所忌者/为病/病在）；**健康字面病一律排除** |

**接口**：`校验/评测/index_query.py` 的 `MultiDimIndex`——

```python
import sys; sys.path.insert(0, r"<技能包>/校验/评测")
from index_query import MultiDimIndex
ix = MultiDimIndex()
ix.query(病=["水"], 药=["火"])         # 同病同药 → [CASE_ID, ...]
ix.query(日主="木", 格局="从格")        # 同格同日主
ix.groups(("药","日主"), min_size=2)   # 可互验组（当前 19 组）
```

**调用铁律**：

1. **只作旁证，不改断语**——与规则冲突时规则优先，命例标"存疑旁证"。
2. **不得早于 P2**——无喜忌卡则无维度可查。
3. **无命中即留空**，写"无同造旁证"，**不硬凑、不编造同造**。
4. 每主题 **≤3 例**，须附原文锚点（章号 ＋ 该例 `判断依据`/`任铁樵原断` 首句）。
5. 改规则库/子技能后须重跑 `build_index.py`，diff 维度统计与新互验组，防提取漂移。
