# 元规则 01 · 五层作者归属与数据口径

> 本包一切判断必须建立在"这句话到底是谁说的"之上。任铁樵《滴天髓阐微》是五层文本的叠加，混层即错。

## 一、五层归属标签（全项目强制）

| 层 | 作者 | 含义 |
|----|------|------|
| L1 | 滴天髓经文 | 经文体，原书正文 |
| L2 | 刘基原注 | 刘伯温原注 |
| L3 | 任铁樵注 | 任氏曰——本包复原的核心 |
| L4 | 徐乐吾整理/补注 | 近代徐乐吾校注整理 |
| L5 | 后世整理增补 | 袁树珊"（新增）"、现代通俗本 |

**五层块计数（v2.0 归属库 `数据/归属库_五层v2.json`）**：

- **L1 经文体 63 块 / 2,063 字**
- **L2 刘基原注 133 块 / 15,447 字**
- **L3 任铁樵注 140 块 / 121,079 字**（v1.0 原样）
- **L4 徐乐吾补注 2,897 块 / 56,748 字**（v2.0 新增）
- **L5 后世增补 565 块 / 2,982 字**（v2.0 新增，孙正治注释·今译）

合计 **3,798 块**。任氏注（L3）体量远超原注——这正是任铁樵"以注代论、借滴天髓立自派"的特点；而 L4 徐补 2,897 块是"后世如何修正发展任氏"的实证。**断"任氏怎么论"只能用 L3；断"徐乐吾怎么补"用 L4。两者不得混。**

> **v1.0 → v2.0 口径变化**：v1.0 时 L4/L5 在原文章节内不独成层（计数为 0），徐氏补注仅由 `ADDED_BY_EDITOR` 或争议清单另行标注。v2.0 并入徐乐吾《滴天髓补注》全本蒸馏后，**L4/L5 已成独立实体层**（来源：`rtq-xlw-底本OCR_全本.md` 逐行 `【L4】/【L5】` 块）。

## 三、命例默认归属

- 出现在 `任氏曰` 块（L3）内的命例 **默认 L3**。
- 原书未列四柱、仅存叙述的命例，八字字段标"不足以确认（原书未列四柱干支）"，**不得自补四柱**。
- 判断不了归属的，标 `[归属不确定]`，不要默认。

## 四、禁止混层

1. 不得把 L4（徐乐吾补注）/L5（后世增补）文字冒认为 L3 任铁樵。
2. 不得因某观点"符合现代命理常识"自动归任。
3. 不得以"排盘"充数——排盘内容不计入任氏断法蒸馏。
4. 证据不足时宁可写"不足以确认"，不得自行补全结论。

## 五、查表方法

- 按章号查层块：`数据/归属库_五层v2.json` → `chapters[]` → `blocks[]`（`BLOCK_ID` 形如 `TS-12-L3-02`；L4/L5 块另带 `SOURCE_LINE` 底本行号）。
- 某条规则属于哪层：`数据/规则库_1538_双层.json` → 该规则 `AUTHOR` 字段（L3 任注 / L4 徐补）。
- 某命例出处是哪层：`数据/命例库_712_双层.json` → `LAYER` + `ADDED_BY_EDITOR`。
- 任徐同造互参：`数据/xlw_L4-L3互参表.json`（12 例）。

> **v1.0 单层文件仍保留**（`规则库_797.json` / `命例库_509.json` / `归属库_五层.json`），供回溯 v1.0 口径；**v2.0 判断统一走双层三件套**。
