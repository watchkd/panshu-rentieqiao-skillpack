# 元规则 04 · 任徐双层与 L4 挂载（v2.0 新增）

> v1.0 的技能包是"纯任氏原版"——归属 100% 落在 L3，后世 300 年的修正完全缺席。v2.0 并入徐乐吾《滴天髓补注》蒸馏成果，**活性化 L4 层**。本篇规定双层的挂载与呈现规则。

## 一、为什么是"平行并入"而不是"改写"

**总装契约 §六「禁止清单 1」明确**：不得把 L4/L5 文字冒认为 L3。因此 v2.0 不做"任氏改写"，而以 **独立前缀、独立层平行补入** 后世补注：

- L3 任注：`RTQ-RULE-…` / `RTQ-CASE-…`（v1.0 原样，一字未改）
- L4 徐补：`RTQ-RULE-XLW-…` / `RTQ-CASE-XLW-…`（v2.0 新增）

两套命名空间**可全库平行检索、可整包回滚**（删除 `*-XLW-*` 即还原 v1.0）。

## 二、双层检索协议（主技能第 3 步）

```
按 CHAPTER_ID 检索
  ├─ 规则库_1538_双层.json 中 AUTHOR=='L3' → 任说（RTQ-RULE-）
  └─ 规则库_1538_双层.json 中 AUTHOR=='L4' → 徐补（RTQ-RULE-XLW-）
两路并出；章号沿用 63 章体系（TS-01~34 / LQ-01~29），同键对齐，无需改表。
```

## 三、双层输出格式

凡所涉主题同章存在 L4 卡时，统一按双层并出：

```
【任说·L3】<任铁樵原文逐字>
【徐补·L4】<徐乐吾补注原文逐字>
```

**层不混淆铁律**：徐氏引述任氏原文再补注的段落，**任氏句标 L3、徐氏句标 L4**，绝不整段标单层。判不了归属标 `[归属不确定]`。

## 四、裁判层（任徐分歧）

当 L4 卡 `NEGATIVE_RULE = 是`（当前 **5 条**）或 `DISPUTED` 非空时，输出额外的裁判层：

```
【任说·L3】<任断>
【徐补·L4】<徐断>
【分歧】任徐于此判不同：<DISPUTED 内容>
        并陈两说，不代读者裁决
```

另在 `对照表_任徐60主题.md` 中，**60 个主题点**已按「同/引申 54 · 异（纠正）5 · 补充 1」分类，其中 **17 条**显式提及任氏。

## 五、命例互参协议（对账优先）

徐氏 203 例中 **12 例**与任氏 509 库同造（`已由任氏收录=是`）。引用时任徐双向给 ID，**只标互参、不重录**：

- 完整对照见 `数据/xlw_L4-L3互参表.json`
- 典型：`RTQ-CASE-XLW-TS-12-003`（甲子丙寅己丑甲子）↔ `RTQ-CASE-TS-25-001` / `RTQ-CASE-LQ-27-002`
- ⚠ 对账注记：L4 组自报 8 例，本次按八字复算实得 12 例，漏判 4 例（TS-28-007 / TS-12-043 / 044 / 045）已逐条核验为真同造并回写。

## 六、L4 覆盖边界（诚实原则）

- **覆盖 25 章**：徐氏只补"任氏所未详"者，依徐序「凡任氏所已详者，概从略」。
- **徐氏未补之章**（TS-17 衰旺、TS-18 中和、TS-21/22 官杀伤官归入 TS-12、LQ-16~23 顺反战合君臣母子等）：**未涉 ≠ 漏蒸**，此时不得臆造"徐乐吾观点"，应明说"徐氏于此未设专章"。
- **`<待核>` 126 处**：底本分歧且校正规则无法判定者，未经 S1 原图定夺前不作确证引用。
- **「七、羁绊」章**：徐氏独有，63 章清单无对应章号，暂挂 `XW-00`。

**检索对策（三层）**：
1. **组级检索**：查合并区成员章时，改为按 `CHAPTER_GROUP` 命中——`CHAPTER_GROUP_MEMBERS` 字段给出该区完整成员列表；
2. **看 `CHAPTER_ACTUAL`**：L4 卡/命例已带该字段，明确"此卡实际涵盖哪些章"；
3. **语义定位**：按 `TEXT` 语义（如含"燥湿/寒暖"关键词）二次筛选，落在正确的成员章。

**性质说明**：此为**上游 L4 蒸馏阶段的已知粗粒度**（`rtq-xlw-章节映射表.md` §3.3 已列为待考项），本轮融合已如实继承并**新增 `CHAPTER_GROUP` / `CHAPTER_GROUP_MEMBERS` / `CHAPTER_ACTUAL` 三字段显式标记**（L4 规则 157 张、命例 40 条），使降级可见、可检索回退。**精确到二级章的重建列为后续可选任务（提升项）。**
