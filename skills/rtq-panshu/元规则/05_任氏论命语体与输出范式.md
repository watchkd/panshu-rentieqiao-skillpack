# 元规则 05 · 任氏论命语体与输出范式（v2.1 新增）

> **本篇是「任铁樵论命风格层」的唯一定义文件。**
> 前述元规则 01~04 解决的是「**断得对不对、出处是什么**」；本篇解决「**断出来像不像任铁樵**」。
> 检索数据只保证"理"对；语体范式才保证"人"对。**做任氏论命而不循本篇，等于用审计报告的口气念任铁樵的注。**

---

## 一、为什么需要本篇（问题定位）

v2.0 及以前，主 SKILL.md 只规定「检索 → 挂 RULE_ID → 结构版结论」。实测后果：

- 输出自动滑向**学术审计体**（表格、评级、清单、附注），读起来像文献综述；
- 任氏原断的**语体特征**（起句、连接词、断语语气）**从未被抽象为可复用范式**；
- 508 例的「任铁樵原断」（平均 109 字、最长 438 字）**只在被"引用"时出现，未被"仿写"**。

**本篇的语料基础**：`命例库_712_双层.json` 中 504 条 L3 任氏原断（有效语料）。以下所有范式与词表**均由该语料频次统计与结构归纳得出**，非臆造。

## 二、任氏原断的「六股骨架」（由 504 例归纳）

任氏批命的标准进程，按出现次序：

```
① 立象    起句定格：「此造…」「此则…」「此以…」「X生于Y月…」
             —— 一句话点出日主、月令、格局气象（14 例用"此造"，另 24 例"此则"）
② 定病    所忌/所嫌：「所忌者…为病」「所嫌者…」「嫌其…」   —— 找出破局之一字
③ 取药    所赖/所喜：「全赖…」「喜其…」「最喜…」「宜…」   —— 出救应之神
④ 验局    更喜/妙在：「更喜…」「更妙…」「妙在…」「所谓…」 —— 加验一层，或点精妙处
⑤ 断人    故/主/是以：「…所以…」「…主…」「…是以…」      —— 落到人事（妻财子禄）
⑥ 系运    运至/及交：「初运…」「及交X运…」「至X运…」       —— 运序吉凶与转折
```

**频次实证（504 例）**：旺 412｜主 123｜**此造 114**｜必 96｜**喜其 92**｜且 89｜通根 89｜清 77｜无根 71｜**病 69**｜**故 67**｜然 67｜**所谓 63**｜更妙 48｜美 48｜宜 47｜衰 46｜当权 40｜用神 36｜盖 26｜**此则 24**｜浊 23｜妙在 17｜中和 16｜**更喜 15**｜嫌其 13｜司令 13｜惜乎 12｜不宜 12｜全赖 11｜喜神 11｜药 10｜虚脱 10｜源头 9

**注意**：「所忌者」仅 3 次、「所赖者」0 次——**精确四字句式并非高频，不可当模板死套**；真正的高频骨架词是 **此造／喜其／更妙／病／故／所谓**。范式要学的是**次序与逻辑**，不是背四字套话。

## 三、连接词与语气词表（供仿写取用）

| 功能 | 首选词（高频） | 次选/备用 |
|---|---|---|
| 起句定格 | 此造、此则、此以、X生于Y月 | 此局、按此造 |
| 定病 | 嫌其、所嫌者、为病、病在 | 忌者、一患、破局者 |
| 取药 | 喜其、最喜、宜、全赖 | 所赖者、得…而解、赖…为救 |
| 加验 | 更妙、更喜、妙在、尤妙 | 又喜、兼之、况 |
| 点精义 | 所谓、此之谓也、盖 | 即…之谓、正是 |
| 转断人事 | 故、所以、是以、主 | 因而、遂、致 |
| 系运 | 初运、及交X运、至X运、运走X方 | 一交、行X地、交X运 |
| 语气保余 | 似、庶几、大约、未可尽执 | 姑断、恐、或 |
| 叹惋（任氏特有） | 惜乎、惜其、可惜 | 美中不足、微嫌 |
| 破俗/对抗（取用自证） | 以俗论之、初看（看似）、俗谓、不知、殊不知 | 世俗以为、人所共认、误矣、如…谓 |
| 判断强度（高→低） | 必、定、主（A级）→ 多、十居八九（B级）→ 似、恐、庶几（C级） |

> **强度词必须与 `CONFIDENCE` 字段一致**：A 级规则可用"必/定/主"，B 级用"多/十居八九"，C 级只能用"似/恐/或"。**禁止把 C 级规则写成"必"**——这是对任氏的忠实度问题，也是防幻觉。

## 四、双层呈现的语体（本包独有：任氏正文 + 徐氏按语）

明清注疏体天然适合「任说为主、徐补为辅」。v2.1 起，凡涉 L4 补注，**按注疏体输出**：

```
【任氏断】用第二节六股骨架，以任氏口吻写，只用 L3 规则。
           例：此造寒金坐禄，印绶当权，足以用火敌寒。所忌者，年干癸水克丁为病，
               全赖月干乙木通根，泄水生火，此喜神即是财星也。…

【按】    徐乐吾补注，以"按"字另起，语气是补注体、不作正文之主断。
           例：按：金水伤官，生于冬令，金寒水冷，调候为急，非见官星不可。
               （徐补·XLW-TS-12-087）

【近人补】孙正治 L5 或公认可验之现代修正（层次须标 L5；无则略去）。
```

**铁律**：
1. 「任氏断」段**不得掺一句 L4/L5 文字**——掺即混层（元规则 04）；
2. 「按」段**不得改写任氏已说者**，只补其未详（徐序「凡任氏所已详者，概从略」）；
3. 任徐于同一判点**相异**时，正文后另起【分歧】并陈（元规则 04 §四），**不在「按」段里替任氏认错**。

## 五、输出体例禁令（可作正文/不可作正文）

**正文必须**：连贯的短段落，用第二三节的骨架与词表；先理后断；一段一意。

**正文禁用**：
- ❌ 表格体作**主断正文**（表格只能进「附录」）；
- ❌ 评级体（★／A级／打分）作主断；
- ❌ 清单体（- 1. 2. 3.）作主断——任氏从不列清单；
- ❌ 现代白话主语「该命主」「用户」「您」；
- ❌ emoji；
- ❌ "综合来看／总而言之"式现代议论文套语（任氏用「由此观之」「总以…为主」）。

**允许的现代辅助（仅附录，且附录默认不出）**：出处清单表、存疑台账表、藏干拆解表。**交付稿默认不含附录**——仅当用户索要「出处／溯源／依据」时才附（走 `--trace` 口径）；藏干拆解若有助于命主读懂，可作**前置「命盘」块**（表在正文之前，不算正文表格）。

## 六、样本锚（Few-shot，供仿写对照）

以下三例摘自 `命例库_712_双层.json`（L3），**逐字原文**，作语体锚例：

**锚例 1（`RTQ-CASE-LQ-01-001`，寒金，含病药加验全骨架）**
> 「此造寒金坐禄，印绶当权，足以用火敌寒。所忌者，年干癸水克丁为病，全赖月干乙木通根，泄水生火，此喜神即是财星也。更喜财星逢合，谓财来就我，其妻贤淑勤能，生三子，皆就书香。」

**锚例 2（`RTQ-CASE-LQ-03-001`，先褒后贬，含运序转折）**
> 「此造官印透而得禄，财星藏而归库，格局未尝不美，所嫌者，丑时伤官肆逞，官星退气，日主衰弱，全赖乙木生火而卫官。年月官印相生，亦出身官家，至亥支入泮；壬戌水通根，破耗异常加捐出仕，不过清规；至酉运，财星坏印，竟伏国刑。」

**锚例 3（`RTQ-CASE-LQ-02-004`，短句直断，含"若…则…"设问收）**
> 「壬水生于孟冬，喜其无金，食神独透，所以书香小就，甲寅入泮，有十子皆育。其不妻者，无财之妙也；秋闱不利者，无地寅卯也。此造如戌土换之以木，青云得路矣。」

> **仿写要诀**：学其**次序**（立象→病→药→验→断）与**句法节奏**（四六短句相间、虚词领起），**不学其具体断语**——具体断语须由本命实际命象与检索到的 RULE_ID 生成。
