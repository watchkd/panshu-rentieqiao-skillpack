## 1. 底本实况（三源）

工作目录 `C:\Users\Administrator\Desktop\任铁樵\滴天髓补注\` 下实有三种同书不同形态的源：

| 代号     | 文件                           | 形态                                | 文本层            | 实测                                        |
| ------ | ---------------------------- | --------------------------------- | -------------- | ----------------------------------------- |
| **S1** | `滴天髓补注-徐乐吾.pdf`              | **315 页手写行楷影印本**（育林出版社）           | **无**（0/315 页） | 全书正文底本，唯一的「真值」来源                          |
| **S2** | `滴天髓补注-孙正治注译2012-扫描.pdf`     | 343 页印刷本扫描（中医古籍出版社，1944×2776 内嵌图） | 无              | rapidocr 逐页 OCR 可用                        |
| **S3** | `滴天髓补注-孙正治注译2012-OCR清洗版.txt` | 9,399 行 / 168,392 汉字              | ✅              | 名为「清洗版」，实为**未清洗的 OCR**（「滴天髋」＝滴天髓、「闸微」＝阐微） |

### 1.1 关键判定：S1 是手写稿，不是印刷本

任务书 §0.1 将 `徐乐吾：滴天髓补注.pdf` 描述为「315 页纯扫描图片（无文本层）」，未点明其为**手写稿**。实测：

- rapidocr 直接跑 S1：**每页仅识别出约 9 个文本块**（正常印刷页约 32～34 块），整页约 400 字仅辨出十余字；
- 高频误识：「任註」→「任真」、「喜忌」→「喜总」；
- **决定性证据**：徐乐吾手稿以「**然**」代「**杀**」（「官然」＝官杀、「七然」＝七杀、「然刃」＝杀刃）。若对手稿做 OCR，这一核心概念会被逐字读丢且无法回改。

> 结论：S1 **不可 OCR**，只能人工视觉校读；且必须作为「真值」用于校核 S2/S3。

### 1.2 S2/S3 与 S1 的关系

孙正治前言明言：**「本书的点校和今译，是依据育林出版社出版的手写影印本进行的」**。故：

```
S1（手写稿，真值）
   └─ 育林出版社手写影印本
         └─ 孙正治点校（2012 中医古籍出版社） ── S2（印刷本扫描）/ S3（点校文本）
```

S2 与 S3 是**同一印本**的两种数字化产物，二者互为独立见证；S1 是二者的共同上游，可用作终审。

## 2. 路线决策：为何不走「315 页直接 OCR」

| 方案        | 内容                                                                     | 判定                                               |
| --------- | ---------------------------------------------------------------------- | ------------------------------------------------ |
| A         | 对 S1 手写稿直接 OCR                                                         | ❌ 完全不可行（§1.1）                                    |
| B         | 仅用 S3 点校文本                                                             | ❌ S3 实为未清洗 OCR，错字密集（「印缓/印绿」＝印绶、「七煊」＝七煞、「睿冲」＝暗冲…） |
| **C（采纳）** | **S3 为骨架（保留 `[原文]/[注释]/[今译]` 分层标记）＋ S2 重跑 OCR 作独立见证 ＋ S1 定点视觉校读作真值仲裁** | ✅                                                |

**选 S3 为骨架的理由**：S3 是唯一**原生带分层标记**的文本——`[原文]`＝徐乐吾补注（L4，本任务目标层）、`[注释]`/`[今译]`＝孙正治（L5）。若改用 S2 重建，分层标记需另行启发式判定，段落级正确率必降。

**选 S2 为见证的理由**：S2 与 S3 是同一印本的两次独立 OCR，二者分歧处**至少一方有误**，可直接定位错误热点；且 S2 的字形识别方向与 S3 不同（S2 偏「简化成常用字」，S3 偏「臆造怪字」），互补性强。

> 与任务书 §4「用 rapidocr 逐页 OCR 315 页」的偏离已记录在案；偏离原因系底本形态与任务书描述不符，属客观不可行，非主观取舍。

### 4.2 错误方向分析（关键发现）

**两个 OCR 的错法完全不同，且各自单向：**

| 错误方向          | 高频实例（S2 侧 → S3 侧）                                                                  | 谁错        |
| ------------- | ---------------------------------------------------------------------------------- | --------- |
| **S3 造怪字**    | 戌→成(132)、酉→西(148)、绶→缓(150)/绿(90)、矣→奂(89)、弱→骏(89)、润→涧(56)、煞→照/煽/熊/煊、宫→客、卯→卵、庚→庞、交→爻 | **S3 错**  |
| **S2 简化为常用字** | 干→千(277)、壬→王(209)、巳→已(271)                                                         | **S2 错**  |
| **双方皆不能自证**   | 已/巳/己 三字互混                                                                         | 待核（427 处） |

> 这解释了为何「以 S3 为骨架」是正确选择：S3 的错字是**可被 S2 检出并规则化修正的怪字**（已修 1,636 处）；而 S2 的错字（千/王）在 S3 中是正确的，用 S3 反而天然规避。
