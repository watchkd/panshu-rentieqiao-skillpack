# 徐乐吾《滴天髓补注》· L4 补注技能

> **填充五层归属库的 L4 层**。v1.0 的技能包是"纯任氏原版"——作者归属 100% 落在 L3（任铁樵），后世 300 年的修正发展完全缺席。本技能把徐乐吾《滴天髓补注》蒸馏成 L4 独立层，与 L3 任注**平行并存、不相互改写**，形成「任说 → 徐补」双层齐备的体系。

## ⚠️ 一、本技能的三条红线（先读，后答）

1. **层不混淆**：徐乐吾补注 = **L4**，任铁樵注 = **L3**。徐氏引述任氏原文再补注的段落，**任氏句标 L3、徐氏句标 L4，绝不整段标 L4**，反之亦然。判不了归属标 `[归属不确定]`。
2. **逐字原文**：徐氏论断必须逐字照录 `TEXT` / `徐乐吾补注` 字段；凡转述显式标注"（转述）"。
3. **不冒认**：不得把徐乐吾的话说成任铁樵，也不得把任氏原文当徐氏补注。本技能与 `rtq-version-collation` 互为保险。

## 二、什么时候用它

- 用户问"**徐乐吾**怎么看这个局 / 这条理论"。
- 用户问"这句话到底是**任铁樵**说的还是**徐乐吾**补的"（走五层归属）。
- 用户问"任徐两人在这点上**有没有分歧**"（走 `DISPUTED` / `NEGATIVE_RULE`）。
- 主断语需要给出"**任说 → 徐补**"双层呈现（主技能第 7 步调用本技能）。

## 四、字段说明（L4 规则卡）

| 字段 | 含义 |
|---|---|
| `RULE_ID` | `RTQ-RULE-XLW-<章>-<序号>`，XLW 即徐乐吾，**与 L3 的 `RTQ-RULE-` 前缀明确区分** |
| `CHAPTER_ID` | 沿用 v1.0 的 63 章体系（TS-01~34 / LQ-01~29），故可与 L3 规则**同键对齐** |
| `TEXT` | 徐氏补注原文逐字 |
| `RULE` / `CONDITION` / `EXCEPTION` / `ORDER` | 论断 / 适用条件 / 例外 / 先后次序 |
| `NEGATIVE_RULE` | **是** = 徐氏纠正任氏或旧说（当前 5 条） |
| `DISPUTED` | 任徐分歧内容（`任断→徐断`），仅当分歧时非空 |
| `SOURCE_FILE` | 出处（底本 `【L4】` 行号），可逐字回溯 |

## 五、使用协议

### 5.1 双层检索（按章并出）
```
按 CHAPTER_ID 检索
  ├─ 规则库_1538_双层.json 中 AUTHOR=='L3' → 任说
  └─ 规则库_1538_双层.json 中 AUTHOR=='L4' → 徐补
两路并出，按 RULE_ID 前缀区分（RTQ-RULE- / RTQ-RULE-XLW-）
```

### 5.2 双层输出
```
【任说·L3】<任铁樵原文>
【徐补·L4】<徐乐吾补注原文>   ← 仅当同章存在 L4 卡时输出
```

### 5.3 裁判层（`NEGATIVE_RULE=是` 或 `DISPUTED` 非空时）
```
【任说·L3】<任断>
【徐补·L4】<徐断>
【分歧】任徐于此判不同：<DISPUTED 内容>
        并陈两说，不代读者裁决
```

### 5.4 命例互参
徐氏 203 例中 **12 例**与任氏 508 库（L3 有效条目）同造（`已由任氏收录=是`，`互参` 字段给出 L3 `CASE_ID`）。引用时**只标互参、不重录**，并给出双向 ID。

## 六、判断标准

**做对了会看到**：先标明这句话属 L3 还是 L4 → 双层并出且各带原文逐字 → 有分歧时显式列 `DISPUTED` 并陈两说 → 同造命例给互参双 ID → 不能确证处标 `[归属不确定]`。

**做错了会看到**：把徐乐吾说成任铁樵（或反之）；整段误标 L4；任徐分歧被压缩成单说；拿徐氏补注当任氏原论下断语。

## 七、什么时候不该用它

- 只问"任铁樵本人怎么断"——走主技能（L3 为主，本技能仅作补充对照）。
- 徐氏**未补**的章（TS-17 衰旺、TS-18 中和、LQ-16~23 顺反战合君臣母子等）：依徐序"凡任氏所已详者概从略"，**未涉 ≠ 漏蒸**，此时不得臆造"徐乐吾观点"，应明说"徐氏于此未设专章"。
- 底本 126 处 `<待核>` 段落：标存疑，不据以立论。
